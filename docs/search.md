# 工作区搜索

关联 RST-19。MCP search 接受必填 query、可选 type（all/issue/spec/project）、limit（1–50，默认 10）和 cursor；fetch 读取 search 返回的 issue:KEY-1、spec:SPEC-1 或 project:数字ID。

查询是忽略大小写的字面片段，不把 %、_ 当通配符。搜索任务标题与正文、Spec 当前版本中的文本、未归档项目名称与说明。不会搜索历史 Spec 版本。精确编号/标题优先，其次标题前缀、标题子串、正文命中；同级按更新时间降序和稳定实体键排序。项目现有模型没有更新时间，结果明确返回 updated_at:null，并在同级中使用稳定键排序，不伪造时间。

SearchRepository 只读跨模块数据，复用 access.visible 与 planning.visibleProject；应用服务先校验工作区成员资格。不可见记录在数据库中被过滤，无 total 或隐藏数量。fetch 重新经过各实体服务，不能用搜索引用绕过私有权限。

分页游标包含匹配级别、微秒精度排序时间和稳定键，绑定用户、工作区、查询文本及实体类型；变更查询后必须重新开始。游标不是授权凭据，每一页重新检查实时可见性。它保证静态结果不重复、不遗漏；分页期间内容发生变更时按最新内容返回，不提供数据库快照。

当前实现使用数据库字面片段匹配，适合现有数据量；没有引入语义搜索或新的搜索索引。自动集成测试覆盖三种实体、中文/通配符字面值、私有数据、归档项目、旧版本、精确时间分页、游标错用和成员停用。
